# RhineCode 用户手册

> 这里是**面向使用者**的深度文档：每个能力怎么配、怎么用、边界在哪。
> 项目的第一印象与 30 秒上手在 [项目 README](../../README.md)。
>
> 想看的是**实现**而不是用法，去 [`docs/internals/`](../internals/architecture.md)；
> 想看某个能力**当初为什么这样设计**，去对应章节的 `docs/c<N>/` 或
> [`docs/extensions/`](../extensions/README.md)。

## 这份手册的由来

它是旧 README 拆出来的。旧 README 长到 1,250 行、按开发顺序堆叠，
第一屏就是 15 行能力表加每条几百字——**对已经在用的人是好东西，对第一次点进来的
陌生人是劝退**。2026-08-30 的重写把「第一印象」留在项目 README，
把这些内容按主题拆成下面十四章，**内容一句没删**，并顺手清掉了当时已知的
十处事实错误（测试条数、目录树里两个不存在的文件、已删除的 `/perm`、
坏链、扩展与命令的计数、trace 事件类数、Skill 体检项数）。
