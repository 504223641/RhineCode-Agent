## 记录格式

每条判据分**两栏**，照 C11 `docs/c11/acceptance/` 的先例：

| 栏 | 写什么 |
| --- | --- |
| **机器判到了什么** | 命令输出、trace 事件、断言结果——**可复现的事实** |
| **据此做的判断** | 从那些事实推出的结论 |

分两栏是因为这两件事经常被混在一起写，而它们的可信度完全不同：
前者可以重跑验证，后者是人的推断。混在一起时，一个错误的推断会伪装成实测结论。
